Lokal.fm — Local Music Streaming

A web application designed to showcase and stream local independent music, featured artists, and curated playlists.

Overview

Lokal.fm is an interactive music streaming interface built to spotlight indie music creators and local soundscapes. It provides users with an intuitive music player experience, seamless playlist browsing, and artist discovery tools in a clean, modern layout.

Role

UI/UX Designer & Frontend Developer — Designed and implemented the user interface, custom audio player controls, interactive playlist navigation, and responsive frontend components.

Features

  • Interactive Web Player: Real-time audio playback controls with track seeking and volume controls.
  • Artist & Album Showcase: Dedicated visual cards highlighting featured independent artists and releases.
  • Curated Playlists: Categorized music feeds based on mood, genre, and trending local tracks.
  • Clean Dark-Themed Audio UI: High-contrast interface optimized for music listening and media playback.
  • Fully Responsive: Optimized layout for seamless audio streaming on mobile devices and desktop screens.
