Overview

Marvel Universe is an interactive character exploration website developed to provide users with an organized way to discover Marvel Comics characters. It retrieves character information through an external API and presents their biographies, appearances, power statistics, and connections through a user-friendly interface.

Role

UI/UX Designer & Frontend Developer — Responsible for designing and developing the website interface, implementing API integration, organizing character information, and building interactive website components.

Features

  • Character Explorer: Browse a collection of Marvel Comics characters and discover their profiles.
  • Search Functionality: Find characters quickly using their names.
  • Character Filters: Organize characters by alignment and gender.
  • Detailed Character Profiles: View biographies, physical appearances, affiliations, and other character information.
  • Power Statistics: Explore character attributes such as intelligence, strength, speed, durability, power, and combat.
  • Pagination: Browse character collections through organized pages.
  • Responsive Interface: Access the website through desktop and mobile devices.
